# Harshdeep Singh — Professional Interactive Portfolio

A responsive interactive portfolio website built from the supplied CV.

## Features
- Modern responsive professional design
- Dark/light theme
- Interactive project detail modals
- Direct GitHub buttons for both CV projects
- Certificate preview modal with original-link button
- Skills, training, achievement, education and contact sections
- Mobile navigation
- Scroll reveal animations
- No framework or installation required

## Important certificate note
The CV contains a local `C://Users/...` file path for the Cisco Python Essentials 1 certificate.
A local path cannot work on a deployed public website, so the website clearly marks that certificate as unavailable online.
Upload the certificate to Google Drive or GitHub and replace the link later.

## Run locally
Open `index.html` in a browser.

## Deploy with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md`.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose `main` and `/ (root)`.
6. Save.

Your site will be available at a GitHub Pages URL.
